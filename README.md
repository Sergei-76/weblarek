# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

# Данные

## IProduct — описание товара
Интерфейс описывает структуру одного товара, получаемого с бэкенда

Поля:
`id:	string`	Уникальный идентификатор товара (UUID).
`title:	string`	Название товара (отображается в каталоге и карточке).
`description:	string`	Подробное описание товара.
`image:	string`	Путь к изображению товара (относительный URL).
`category: string`	Категория товара (используется для фильтрации и группировки).
`price:	number | null`	Цена товара в условных единицах. Может быть null, если товар недоступен для покупки.

### TPayment — способы оплаты
Тип-перечисление допустимых способов оплаты, используемых в системе.

`export type TPayment = 'card' | 'cash'`
Значения: 'card' — оплата банковской картой; 'cash' — оплата наличными.

#### IBuyer — данные покупателя
Интерфейс описывает данные покупателя, необходимые для оформления заказа.

Поля:
`payment:	TPayment | null`	Выбранный способ оплаты ('card' или 'cash').Может быть `null`, если способ не выбран.
`email:	string`	Электронная почта покупателя.
`phone:	string`	Контактный телефон покупателя.
`address:	string`	Адрес доставки заказа.

# Модели данных

## Класс ProductCatalog

Модель каталога товаров. Отвечает за хранение массива всех товаров, доступных для покупки, и управление товаром, выбранным для подробного отображения. Класс используется как источник данных для представления каталога и карточки товара.

Конструктор класса не принимает параметров.

Поля класса:
`products: IProduct[]` — хранит массив всех товаров, загруженных с сервера. Источник данных для отрисовки списка товаров, фильтрации и поиска.
`selectedProduct: IProduct | null` — хранит товар, выбранный пользователем для подробного отображения. Используется при открытии карточки товара. Изначально равен null.

Методы класса:
`saveProducts(products: IProduct[]): void` — сохранение массива товаров, полученного из API или другого источника. Принимает массив товаров и полностью заменяет текущий.
`getProducts(): IProduct[]` — возвращает массив всех товаров, хранящихся в каталоге.
`getProductById(id: string): IProduct | null` — поиск товара по идентификатору. Принимает строковый id, возвращает найденный товар или null, если товара с таким id нет.
`setSelectedProduct(product: IProduct): void` — сохраняет товар для подробного отображения. Принимает объект товара.
`getSelectedProduct(): IProduct | null` — возвращает товар, сохранённый для подробного отображения, или null, если товар не выбран.

### Класс Basket

Назначение и зона ответственности: класс отвечает за хранение товаров, которые пользователь выбрал для покупки. Управляет состоянием корзины: добавление, удаление, очистка, подсчёт общей стоимости и количества товаров, проверка наличия товара по id.

Конструктор класса не принимает параметров.Инициализирует внутренний массив товаров пустым значением.

Поля класса:
`items:	IProduct[]`	Хранит массив товаров, добавленных пользователем в корзину.

Методы класса:
`getItems(): IProduct[]`	Возвращает массив всех товаров, находящихся в корзине.
`addItem(product: IProduct): void ` Добавляет переданный товар в конец массива корзины.
`removeItem(product: IProduct): void` Удаляет товар из массива корзины по его id. Если товар не найден, массив остаётся без изменений.
`clear(): void` Очищает корзину, заменяя массив товаров на пустой.
`getTotalPrice(): number ` Возвращает суммарную стоимость всех товаров в корзине.
`getCount(): number` Возвращает количество товаров в корзине.
`hasItem(id: string): boolean` Проверяет наличие товара в корзине по его идентификатору.

#### Класс Customer
Класс реализует модель данных покупателя и отвечает за хранение, обновление, очистку и валидацию контактных и платёжных данных. Используется в связке с корзиной и API-слоем для оформления заказа.

Конструктор класса не принимает параметров.

Поля класса:
`payment: TPayment | null`  способ оплаты (по умолчанию `null`).
`address: string ` адрес доставки.
`phone: string` номер телефона.
`email: string` электронная почта.

Методы класса:

`saveData(data: IBuyer): void` сохранение данных покупателя. Принимает объект, соответствующий интерфейсу IBuyer, и обновляет только те поля, которые переданы (частичное обновление). Если какое‑либо поле не указано, его значение не изменяется.

`getData(): IBuyer` получение всех текущих данных покупателя в виде объекта, соответствующего интерфейсу IBuyer. Возвращает актуальные значения payment, address, phone, email.

`clear(): void` очистка данных покупателя. Сбрасывает адрес, телефон и email в пустые строки, а способ оплаты устанавливает в значение по умолчанию ('card').

`validate(): IBuyerErrors` валидация данных покупателя. Принимает объект IBuyer и возвращает объект ошибок IBuyerErrors, где ключи — имена полей, а значения — тексты сообщений об ошибках.

# Предстовление

## Класс Card

Абстрактный базовый класс для карточек товаров. Задает унифицированную структуру отображения заголовка и цены, обеспечивает типобезопасную работу с DOM‑элементами через утилиту ensureElement. Служит основой для специализированных карточек (например, ProductCard, BasketCard). Не предназначен для прямого инстанцирования — используется только через наследование.

Конструктор класса принимает один параметр.

Поля класса:

`titleElement: HTMLElement` — элемент для отображения заголовка карточки (селектор .card__title).
`priceElement: HTMLElement` — элемент для отображения цены карточки (селектор .card__price).
Методы и сеттеры класса:

`set title(value: string`) — установка заголовка карточки. Принимает строку и записывает её в textContent элемента titleElement.

`set price(value: number | null)` — установка цены карточки. Принимает число или null. Если передано число, отображает значение с суффиксом «синапсов». Если передано null, отображает текст «Бесценно».

### Класс ServiceCart

Абстрактный базовый класс для карточек услуг в корзине. Расширяет функционал базового класса Card, добавляя отображение категории с модификатором и загрузку изображения из CDN. Предназначен исключительно для наследования — не используется напрямую. Интегрирован с константами проекта (categoryMap, CDN_URL) для единообразного оформления и загрузки ресурсов.

Конструктор класса принимает один параметр.

Поля класса:

`categoryElement: HTMLElement` — элемент для отображения категории услуги (селектор .card__category).
`imageElement: HTMLImageElement` — элемент <img> для отображения изображения услуги (селектор .card__image).

Методы и сеттеры класса:

`set category(value: string)` — установка категории услуги. Принимает строку с названием категории. На основе categoryMap подбирает соответствующий BEM‑модификатор и добавляет его к элементу категории. Одновременно обновляет текстовое содержимое элемента. Если категория не найдена в categoryMap, применяется модификатор `card__category_other`.

`set image(value: string)` — установка изображения услуги. Принимает относительный путь к файлу. Если значение не пустое, формирует полный URL через CDN_URL и передаёт его в метод setImage вместе с альтернативным текстом «Изображение товара». Делает элемент видимым. Если значение пустое или отсутствует, скрывает изображение через свойство hidden.


#### Класс Gallery

Класс реализует компонент галереи — отвечает за управление содержимым контейнера: добавление, замену и очистку набора элементов. Работает с отдельными DOM‑элементами либо с их массивом, автоматически нормализуя входные данные. Наследуется от базового класса Component, использует его инфраструктуру для работы с корневым контейнером.

Конструктор класса принимает один параметр.

Поля класса:

`container: HTMLElement` — корневой элемент галереи, унаследован от базового класса Component. Через него происходит вся манипуляция содержимым.
Методы и сеттеры класса:

`set items(items: HTMLElement[] | HTMLElement)` — установка содержимого галереи. Принимает либо отдельный элемент HTMLElement, либо массив элементов. Внутри сеттера входные данные нормализуются: если передан один элемент, он оборачивается в массив. Затем текущее содержимое контейнера полностью заменяется на новые элементы с помощью replaceChildren(...list). Это гарантирует, что в галерее всегда отображается только актуальный набор элементов без накопления дублей или «мусорных» узлов.

##### Класс Header

Класс реализует компонент шапки сайта — отвечает за отображение кнопки корзины и счётчика товаров, а также за генерацию события открытия корзины. Наследуется от базового класса Component, интегрирован с системой событий (IEvents) для координации взаимодействия между частями приложения (корзина, каталог, формы).

Конструктор класса принимает два параметра.

Поля класса:

`basketButtonElement: HTMLButtonElement` — кнопка вызова корзины (селектор .header__basket).
`counterElement: HTMLElement` — элемент для отображения количества товаров в корзине (селектор .header__basket-counter).
Методы и сеттеры класса:

`set counter(value: number)` — установка значения счётчика товаров. Принимает число, преобразует его в строку и записывает в textContent элемента counterElement.

##### Класс Modal

Класс реализует универсальный модальный компонент — отвечает за открытие, закрытие, установку произвольного содержимого и обработку кликов вне области окна. Наследуется от базового класса Component, использует утилиту ensureElement для типобезопасного поиска внутренних элементов. Предназначен для показа уведомлений, форм (например, SuccessForm), списков товаров и любого другого DOM‑контента в модальном окне.

Конструктор класса принимает один параметр.

Поля класса:

`closeButtonElement: HTMLButtonElement` — кнопка закрытия модального окна (селектор .modal__close).

`contentElement: HTMLElement` — область для размещения пользовательского контента (селектор .modal__content).

`windowElement: HTMLElement` — внутренний контейнер модального окна, ограничивающий область клика (селектор .modal__container).

`_isOpen: boolean` (приватное) — внутренний флаг состояния: true, если модалка открыта.

Методы и сеттеры класса:

`set content(value: HTMLElement)` — заменяет всё содержимое модалки на переданный элемент (через replaceChildren). Удобно для динамической подмены форм внутри окна.

`open(): void` — показывает модалку: добавляет CSS‑класс modal_active к контейнеру и устанавливает _isOpen = true.

`close(): void` — скрывает модалку: убирает класс modal_active, очищает содержимое (replaceChildren()) и ставит _isOpen = false.

`isOpen(): boolean` — возвращает текущее состояние видимости модалки. Позволяет презентеру проверять, открыта ли она, без анализа DOM.

`render(data: IModalData): HTMLElement` — рендерит содержимое и сразу открывает окно. Вызывает super.render(data), затем this.open() и возвращает контейнер.

##### Класс PreviewBasket

Класс реализует компонент предпросмотра корзины — отвечает за отображение итоговой суммы, списка товаров и кнопки оформления заказа. Наследуется от базового класса Component, интегрирован с системой событий (IEvents) для передачи сигнала о начале оформления заказа. Используется как часть модального окна корзины или отдельной панели предпросмотра.

Конструктор класса принимает два параметра.

Поля класса:

`buttonArrangeElement: HTMLButtonElement` — кнопка «Оформить заказ» (селектор .basket__button).
`subtotalElement: HTMLElement` — элемент для отображения итоговой суммы заказа (селектор .basket__price).
Методы и сеттеры класса:

`set subtotal(value: number)` — установка итоговой суммы заказа. Принимает число и отображает его в элементе subtotalElement с суффиксом «синапсов».

`disabled(value: boolean)` — управление доступностью кнопки оформления заказа. Принимает булево значение и устанавливает свойство disabled у кнопки buttonArrangeElement. Используется для блокировки действия, если корзина пуста или не заполнены обязательные данные.

##### Класс BasketCard

##### Класс ProductCard

Класс реализует карточку товара в каталоге — отвечает за отображение товара (заголовок, цена, категория, изображение) и обработку клика по всей карточке для добавления в корзину или открытия предпросмотра. Наследуется от ServiceCart, переиспользуя его логику работы с категорией и изображением. Реагирует на клик по контейнеру карточки через переданный обработчик, при этом корректно предотвращает всплытие события.

Конструктор класса принимает два параметра.

Поля класса:
В классе не объявлены дополнительные DOM‑поля: используется базовый container из Component (и ServiceCart) — вся логика строится вокруг него.

Методы и особенности поведения:

Обработка клика по карточке: если при создании передан actions.onClick, на container навешивается слушатель события click. При срабатывании вызывается ev.stopPropagation(), чтобы клик не «проваливался» на родительские элементы (например, на сетку каталога или пагинацию), и затем выполняется actions.onClick().
Наследование функционала ServiceCart: карточка автоматически поддерживает установку категории (с модификаторами через categoryMap) и загрузку изображения из CDN — эти возможности доступны через сеттеры базового класса.

##### Класс ServiceForm

Базовый абстрактный класс для всех форм приложения — задаёт типовое поведение: управление кнопкой отправки и вывод ошибок. Наследуется от Component, использует утилиту ensureElement для безопасной работы с DOM.

Конструктор класса принимает два параметра в порядке: container: HTMLElement, `submitButtonSelector: string | null = null.`

Поля класса:

`submitButton?: HTMLButtonElement` — кнопка отправки (ищется по переданному селектору; может отсутствовать).
`errorsElement: HTMLElement` — элемент для отображения сообщений об ошибках (селектор .form__errors; обязательно присутствует — ищется через ensureElement).

Методы и сеттеры класса:

`set valid(value: boolean)` — включает или отключает кнопку отправки: если value === false, устанавливает disabled = true. Если кнопка не найдена, операция пропускается без ошибок.

`set errors(value: string)` — выводит сообщения об ошибках: записывает переданную строку в textContent элемента errorsElement. Передача пустой строки скрывает блок ошибок.

##### Класс OrderForm
Класс реализует компонент формы оформления заказа — отвечает за сбор данных о способе оплаты и адресе доставки, валидацию состояния формы и генерацию событий для координации с внешними слоями (контроллер корзины, API‑слой). Наследуется от базового класса Component, интегрирован с системой событий IEvents для реактивного обновления состояния без прямого доступа к DOM в других частях приложения.

`addressInput: HTMLInputElement` — поле ввода адреса доставки (селектор .form__input).

`orderButton: HTMLButtonElement` — кнопка отправки заказа (селектор .order__button).

`set address(value: string)` — установка значения поля адреса. Напрямую записывает переданную строку в value инпута, не вызывая событий — это удобно для программной инициализации (например, из сохранённых данных пользователя).
